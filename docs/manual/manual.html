1 · เริ่มต้นใช้งานและรู้จักเมนู

เปิดหน้าเว็บ

หน้าเว็บต้องเปิดผ่านเซิร์ฟเวอร์เล็กๆ ในเครื่อง (ไม่ใช่ดับเบิลคลิกไฟล์ index.html ตรงๆ) เพราะส่วนกล้องและการเลือกโฟลเดอร์ต้องการที่อยู่แบบ http://

  1. ติดตั้ง Python ครั้งเดียว (python.org ติ๊ก "Add python.exe to PATH")
  2. ดับเบิลคลิก tools/cctv/start-cctv.bat โปรแกรมจะเปิดเซิร์ฟเวอร์พอร์ต 5510 แล้วเปิด Chrome ให้เอง
  3. หรือเปิดเองที่ http://localhost:5510/index.html (ถ้ารัน python -m http.server 5510 ในโฟลเดอร์โปรเจกต์)
รู้ไว้: ตอนเปิดหน้า จะมีวงกลมหมุน "กำลังโหลดข้อมูล..." แล้วขึ้นป้ายสั้นๆ มุมจอ ✅ โหลดข้อมูลเสร็จแล้ว พร้อมใช้งาน เมื่อโหลดเสร็จ ถ้าขึ้น ❌ โหลดข้อมูลไม่สำเร็จ แปลว่าติดต่อฐานข้อมูลไม่ได้ (ดูบทที่ 9)

📹 กล้อง CCTVดูภาพสด / ย้อนหลังจากโปรแกรม RRQC Camera

ของที่ใช้ได้ทุกหน้า

🔊 ระดับเสียงแจ้งเตือน QCแถบเลื่อนมุมล่างของเมนูซ้าย ปุ่ม ▶ ใช้ทดสอบเสียง เสียงแยก 3 แบบ: สแกนถูก · ผิด/ซ้ำ · ครบออเดอร์
📷 ปุ่มกล้องข้างช่องสแกนบนมือถือ กดแล้วใช้กล้องมือถืออ่านบาร์โค้ด/QR แทนเครื่องสแกน
ช่องสแกนเครื่องสแกนทำงานเหมือนคีย์บอร์ด ยิงแล้วเติมข้อความตามด้วย Enter เอง ช่องที่มีเคอร์เซอร์อยู่จะรับค่า
ข้อความแจ้งเตือนกล่องแจ้งผลสีเขียว/แดงด้านบนหน้า หายเองใน 4 วินาที ส่วนการลบ/ยกเลิก จะมีกล่องถามยืนยันก่อนเสมอ

2 · ตรวจสอบสินค้า (QC Scan)

ใช้ตรวจว่าของในออเดอร์ตรงกับที่ต้องส่งหรือไม่ ก่อนแพ็ค

  1. ยิง Tracking No. ที่ช่องบน (หรือพิมพ์แล้วกด Enter) ระบบจะเปิดรายการสินค้าในออเดอร์ พร้อมป้าย "สแกนแล้ว 0 / N ชิ้น"
  2. ยิงสินค้าทีละชิ้น ด้วยบาร์โค้ดหรือ SKU ระบบรู้ว่าบาร์โค้ด (GTIN) คือ SKU ไหนจากหน้า "จัดการสินค้า" แล้วนับให้
  3. เมื่อครบทุกชิ้น ออเดอร์เปลี่ยนเป็น QC แล้ว อัตโนมัติ มีเสียงครบออเดอร์ แล้วหน้าจอเคลียร์พร้อมออเดอร์ถัดไป

ข้อความที่อาจเจอ

ข้อความความหมาย / ต้องทำอะไร
❌ ไม่พบข้อมูล Tracking No. นี้ในระบบออเดอร์นี้ยังไม่ถูกนำเข้า ให้ไปอัปโหลดที่หน้า "ทำ ฟวย" หรือตรวจเลขที่ยิง
⚠️ ออเดอร์ … ผ่าน QC ไปแล้วเมื่อ …ตรวจไปแล้ว ถ้าต้องตรวจใหม่ ให้ไปหน้า Orders กด "🔄 ยกเลิก" ที่ออเดอร์นั้นก่อน
❌ สินค้า SKU/บาร์โค้ด [..] ไม่อยู่ในออเดอร์นี้!หยิบของผิด หรือสินค้านี้ถูกเปลี่ยนทดแทน (ดูบทที่ 6) เสียงเตือนผิดดังขึ้น
⚠️ สินค้า SKU [..] ครบจำนวนแล้ว!ยิงเกินจำนวนที่สั่ง ตรวจว่าหยิบเกินหรือยิงซ้ำ
👍 สแกน … สำเร็จ (1/2)ถูกต้อง ยิงต่อ

โหมด "ยิงผ่าน (ข้าม SKU)"

ติ๊กช่อง ยิงผ่าน (ข้าม SKU) ที่มุมขวาบนของหน้า เมื่อยิง Tracking ออเดอร์จะผ่าน QC ทันทีโดยไม่ต้องยิงสินค้าทีละชิ้น (บันทึกสถานะเป็น "ไม่ได้ตรวจ" เพื่อแยกจากที่ตรวจจริง) เครื่องจำค่าที่ติ๊กไว้

ระวัง: โหมดนี้ข้ามการตรวจของจริงทั้งหมด ใช้เฉพาะเมื่อมั่นใจ และอย่าลืมปิดเมื่อกลับมาตรวจตามปกติ

3 · รายการออเดอร์ (Orders)

แสดงออเดอร์ทั้งหมดในระบบ คอลัมน์: Tracking No. · รายการสินค้า (จำนวน) · สถานะ QC · เวลาที่ QC · จัดการ

🔍 ค้นหาพิมพ์หรือยิง Tracking No. หรือ SKU ในช่องค้นหา ผลกรองทันที
📋 หลายรายการกดแล้ววาง Tracking หลายเลข (บรรทัดละเลข สูงสุด 3,000 ตัวอักษร) เพื่อค้นหาพร้อมกันทีเดียว

สถานะและปุ่มจัดการ

สถานะความหมาย
รอ QCยังไม่ได้ตรวจ
QC แล้วตรวจแล้ว แสดงเวลาที่ตรวจ ปุ่ม 🔄 ยกเลิก ย้อนกลับเป็น "รอ QC" (มีกล่องถามยืนยัน)

รายการยาวจะแบ่งหน้า ใช้ปุ่มเลขหน้าด้านล่างตาราง

เคล็ดลับ: ตรวจซ้ำออเดอร์ที่ผ่านไปแล้วไม่ได้โดยตรง ต้องยกเลิกที่หน้านี้ก่อน เพื่อกันการยิงซ้ำโดยไม่ตั้งใจ

4 · ทำ ฟวย

หน้านี้ใช้นำเข้าไฟล์ Excel ประจำวัน แล้วดูสรุปว่าอะไรค้าง/เจอ/หาย/ส่งแล้ว และเช็คของที่หาเจอ

A · อัปโหลดไฟล์

  1. กด เลือกไฟล์ เลือก .xlsx หรือ .xls ตัวอย่างข้อมูลจะแสดงในตารางด้านล่าง
  2. กด ⬆️ อัปโหลด แล้วกดยืนยัน ระบบ แทนที่ข้อมูล ฟวย เดิมทั้งหมด ด้วยข้อมูลในไฟล์ และแทนที่รายการออเดอร์ทั้งหมดในหน้า Orders ด้วยข้อมูลจากไฟล์เดียวกัน
สำคัญ: อัปโหลดแล้วออเดอร์เดิมที่ไม่อยู่ในไฟล์จะหายไปจากระบบ ทำก่อนเริ่มงานรอบใหม่ ไม่ใช่ระหว่างตรวจ

B · อ่านกล่องสรุป

กล่องสรุปมี 3 แถว ตามหมวด วิกฤติ · ยิง · แฟลช แต่ละแถวมีช่อง:

ช่องความหมาย
… ออกได้จำนวนทั้งหมดของหมวดนั้นในไฟล์ (ตัวเลขดิบ)
เจอรายการที่เช็คแล้ว (ยังไม่ส่ง)
หายยังไม่ได้เช็ค (ยังไม่ส่ง) เจอ + หาย = ค้างรวม
ส่งออเดอร์ที่ ผ่าน QC แล้ว (ถือว่าส่งออกไปแล้ว) นับเฉพาะช่องนี้ ไม่ถูกนับซ้ำใน เจอ/หาย/ค้าง
ค้างที่ยังไม่ส่งทั้งหมด (เจอ + หาย)

ทุกช่องกดได้ ตารางข้างล่างจะกรองและสลับไปคอลัมน์หมวดนั้น แถวที่ "เจอ" แล้วมีพื้นหลังจางๆ ตามสีหมวด (ค้าง ว = แดง · ค้าง ย = ส้ม · วิกฤติ = ม่วง · ยิง = ฟ้า · แฟลช = เหลือง)

C · เช็ครายการที่หาเจอ

  1. ยิงหรือพิมพ์ Tracking ที่ช่อง "สแกน หรือกรอก Tracking No. เพื่อเช็ค" แล้ว Enter
  2. ระบบแจ้งว่าเป็นของหมวดไหน (ใช้สีตามหมวด ค้างข้อความ 5 วินาที) ถ้าเลขนั้นไม่อยู่ในออเดอร์จะไม่บันทึก
  3. ปุ่ม ✅ ดูรายการที่เช็คแล้วทั้งหมด (N) เปิดรายการที่เช็คไปแล้ว
  4. ปุ่ม 🔄 รีเซ็ต ล้างรายการที่เช็คทั้งหมดเพื่อเริ่มรอบใหม่ (มีกล่องถามยืนยัน ย้อนกลับไม่ได้)
เคล็ดลับ: ออเดอร์ที่ผ่าน QC แล้วจะมีป้าย ✅ ส่งแล้ว ในตารางด้านล่าง และถูกตัดออกจาก เจอ/หาย/ค้าง ให้เอง ดังนั้นควรตรวจ QC ในหน้า "ตรวจสอบสินค้า" ให้เรียบร้อยก่อนมาดูสรุป

5 · จัดการสินค้า (Products)

เป็นรายการสินค้าหลัก ใช้จับคู่ "บาร์โค้ด" กับ "SKU" ตอน QC และแสดงชื่อแบรนด์ในตาราง

เพิ่ม / แก้ / ลบทีละรายการ

  • กรอก แบรนด์/หมวดหมู่, SKU Merchant (จำเป็น), GTIN / บาร์โค้ด (ยิงด้วยเครื่องสแกนได้) แล้วกด ➕ เพิ่มสินค้า
  • ในตารางด้านล่าง กดปุ่ม ✏️ แก้ไข ที่แถว ข้อมูลจะขึ้นด้านบนให้แก้ แล้วกด 💾 บันทึกการแก้ไข หรือ ✖️ ยกเลิก
  • ปุ่ม 🗑️ ลบ ลบแถวนั้น (ถามยืนยันก่อน) ช่องค้นหาด้านบนตารางหาได้ทั้งแบรนด์ SKU และ GTIN

นำเข้าสินค้าจาก Excel

  1. เลือกไฟล์ .xlsx/.xls (เลือกได้หลายไฟล์พร้อมกัน)
  2. เลือกว่าคอลัมน์ไหนคือ SKU Merchant (จำเป็น), แบรนด์/หมวดหมู่, GTIN / บาร์โค้ด ตัวอย่างในตารางจะบอกว่าแถวไหน "จะนำเข้า"
  3. กด 🗑️⬆️ ลบทั้งหมด แล้วนำเข้าใหม่ แล้วยืนยัน
อันตราย: ปุ่มนี้ ลบสินค้าเดิมทุกรายการ แล้วใส่ข้อมูลจากไฟล์แทนทั้งหมด ย้อนกลับไม่ได้ ต้องแน่ใจว่าไฟล์มีสินค้าครบ (ระบบมีสินค้ามากกว่า 27,000 รายการ) ถ้าอยากแค่เพิ่ม ให้รวมของเดิมไว้ในไฟล์ หรือเพิ่มทีละรายการ

6 · สินค้าทดแทน และ ตัดสินค้าออกจากออเดอร์

ใช้เมื่อของจริงที่ส่งไม่ตรงกับออเดอร์ เพื่อให้ QC ยิงผ่านได้โดยไม่ต้องแก้ไฟล์ออเดอร์ เมนูอยู่ใต้ 🔄 สินค้าทดแทน (Substitutes) กดที่ชื่อเมนูเพื่อเปิดเมนูย่อย

🔄 เปลี่ยนสินค้าทดแทน

ใช้เมื่อส่ง SKU อื่นแทนของที่สั่ง

  1. ใส่ Tracking No.
  2. แต่ละแถว เลือก SKU เดิม (จากสินค้าในออเดอร์นั้น) ใส่ จำนวน แล้วเลือก/พิมพ์ SKU ใหม่ กด ➕ เพิ่มรายการ เพื่อเพิ่มแถว
  3. กด 💾 บันทึกสินค้าทดแทน
กฎที่ระบบบังคับ: เลือก SKU เดิมซ้ำกันไม่ได้ · จำนวนที่ทดแทนมากกว่าจำนวนในออเดอร์ไม่ได้ · เพิ่มแถวได้ไม่เกินจำนวนรายการ SKU ที่มีในออเดอร์นั้น (เช่น ออเดอร์มี 3 SKU เพิ่มได้ 3 แถว)

🗑️ ตัดสินค้าออกจากออเดอร์

ใช้เมื่อสินค้าบางรายการไม่ได้ส่ง (ของหมด/ยกเลิก) ให้ QC ไม่ต้องยิงรายการนั้น

  1. ใส่ Tracking No. เลือก SKU ที่ต้องการตัดออกและจำนวน (เพิ่มได้หลายแถวด้วย ➕ เพิ่มรายการ)
  2. กด 🗑️ บันทึกตัดออก แล้วยืนยัน

ทั้งสองหน้ามีตารางประวัติด้านล่าง ค้นหาด้วย Tracking หรือ SKU ได้ และมีปุ่ม 🗑️ ลบ เพื่อยกเลิกรายการที่บันทึกผิด (ถามยืนยันก่อน)

เคล็ดลับ: ถ้ายิงสินค้าตอน QC แล้วขึ้น "ไม่อยู่ในออเดอร์นี้" ทั้งที่หยิบถูก ให้ตรวจว่าควรบันทึกสินค้าทดแทนไว้ก่อนหรือไม่

7 · ประวัติการยิงสแกนเนอร์ และ RRQC Scanner

บันทึกการยิงทุกครั้ง เพื่อตรวจย้อนหลังว่าใครยิงอะไร เมื่อไร จากเครื่องไหน เก็บเฉพาะรหัสที่ขึ้นต้นด้วย TH หรือ SPX (ไม่สนตัวพิมพ์เล็ก/ใหญ่)

หน้า "ประวัติการยิงเครื่องสแกนเนอร์"

  • เลือก วันที่ (ค่าเริ่มต้นคือวันนี้) · ค้นหารหัส · กรอง 🖥️ เครื่อง (ทุกเครื่อง / ชื่อเครื่อง / 🌐 เว็บเบราว์เซอร์) · ปุ่ม 🔄 รีเฟรช
  • แถบสรุปด้านบน: ทั้งหมด · Tracking · สินค้า · ไม่พบในระบบ
  • ตาราง: เวลา · รหัสที่ยิง · ประเภท · เครื่อง · ยิงที่หน้า/โปรแกรม (ถ้ายิงตอนอยู่โปรแกรมอื่น จะบอกชื่อโปรแกรม เช่น "โปรแกรมอื่น (chrome)")
  • ข้อมูลเก่ากว่า 1 เดือนถูกลบอัตโนมัติทุกวันเวลา 03:00 น.

โปรแกรม RRQC Scanner (บันทึกการยิงในทุกโปรแกรม)

หน้าเว็บจับการยิงได้เฉพาะตอนเปิดเว็บอยู่ ถ้าต้องการบันทึกการยิงแม้กำลังใช้โปรแกรมอื่น ให้ติดตั้ง RRQC Scanner บนคอมที่ต่อเครื่องสแกน

  1. คัดลอกไฟล์ RRQCScanner.exe ไปไว้ที่ถาวร เช่น C:\RRQC\ (ถ้ายังไม่มีไฟล์ ดับเบิลคลิก tools/scanner-logger/build.bat เพื่อสร้าง)
  2. ดับเบิลคลิกเปิด ถ้า Windows ขึ้น "Windows protected your PC" กด More info → Run anyway
  3. ติ๊ก เปิดโปรแกรมอัตโนมัติพร้อมวินโดวส์
  4. ตั้ง ชื่อเครื่องนี้ เช่น "โต๊ะแพ็ค 1" (ค่าเริ่มต้นคือชื่อคอม) แล้วกด บันทึก ชื่อนี้จะแสดงในหน้าประวัติของเว็บ
  5. ลองยิงรหัส TH… สักครั้ง ในหน้าต่างโปรแกรมต้องมีแถวใหม่สถานะ "ส่งแล้ว ✓"
ส่วนของโปรแกรมทำอะไร

ตัวเลขยิงวันนี้ · ส่งขึ้นระบบแล้ว · รอส่ง

หยุดชั่วคราวปุ่มหยุดเมื่อไม่ต้องการให้จดชั่วคราว
ปิดหน้าต่างไม่ได้ปิดโปรแกรม แค่ซ่อนไปที่ไอคอนถาดระบบ ออกจริงให้คลิกขวาที่ไอคอน → ออกจากโปรแกรม
ติดตั้งหลายเครื่อง: ใช้ไฟล์ .exe เดียวกัน ทุกเครื่องส่งเข้าฐานข้อมูลเดียวกัน แยกกันด้วย "ชื่อเครื่อง" ในหน้าประวัติ อย่าเปิดซ้ำในเครื่องเดียวกัน (โปรแกรมจะเตือน) · โปรแกรมอ่านรหัสได้แม้แป้นพิมพ์เป็นภาษาไทย แต่ช่องกรอกในเว็บยังควรใช้แป้น EN

ข้อมูลของโปรแกรมเก็บที่ %APPDATA%\RRQC-Scanner\ (ตั้งค่า + สำเนาสำรองการยิง)

8 · กล้อง CCTV และโปรแกรม RRQC Camera

มี คอมเครื่องหลัก 1 เครื่อง ที่เสียบกล้อง EMEET ทำหน้าที่เปิดกล้อง จับความเคลื่อนไหว และเก็บคลิป เครื่องอื่น (คอม/มือถือ) ใช้หน้าเว็บ "กล้อง CCTV" เพื่อดูเท่านั้น

A · ติดตั้งบนคอมเครื่องหลัก (ทำครั้งเดียว)

  1. ดาวน์โหลด ffmpeg (build "essentials" จาก gyan.dev/ffmpeg/builds) แตกไฟล์ แล้วเอา ffmpeg.exe (อยู่ในโฟลเดอร์ bin) ไปวางในโฟลเดอร์เดียวกับ RRQCCamera.exe
  2. ถ้ายังไม่มี RRQCCamera.exe ให้ดับเบิลคลิก tools/camera/build.bat เพื่อสร้าง
  3. เปิด RRQCCamera.exe ถ้า Windows Firewall ถาม ให้กด อนุญาต (เครือข่ายส่วนตัว)
  4. โปรแกรมเลือกกล้องตัวแรกให้เอง เลือกความละเอียด/ความไว/โฟลเดอร์เก็บคลิป แล้วกด บันทึกและใช้ค่านี้ ติ๊ก เปิดพร้อมวินโดวส์ ถ้าต้องการ

วงกลมหมุน "กำลังโหลดข้อมูล" ไม่จบ / ป้ายแดงตรวจอินเทอร์เน็ต แล้วกด Ctrl+F5 ถ้ายังไม่หาย แจ้งผู้ดูแลตรวจ Supabase

RRQC Scanner

อาการวิธีแก้
ยิงตอนอยู่โปรแกรมอื่นแล้วไม่ขึ้นในหน้าประวัติตรวจว่าโปรแกรม RRQC Scanner เปิดอยู่ (ไอคอนในถาดระบบ) ป้ายเป็น "กำลังทำงาน" และรหัสที่ยิงขึ้นต้นด้วย TH/SPX
ป้ายแดง "ส่งไม่ได้ (ออฟไลน์)"ตรวจอินเทอร์เน็ต รายการที่ค้างจะส่งให้เองเมื่อเน็ตกลับมา
Windows บล็อกไฟล์ / ขึ้น SmartScreenกด More info → Run anyway หรือคลิกขวาไฟล์ → Properties → ติ๊ก Unblock โปรแกรมป้องกันไวรัสบางตัวอาจบล็อกเพราะดักการกดแป้น ให้เพิ่มเป็นข้อยกเว้น

กล้อง

อาการวิธีแก้
เว็บขึ้น "ติดต่อโปรแกรมกล้องไม่ได้"ตรวจ 1) โปรแกรม RRQC Camera เปิดอยู่ที่เครื่องหลัก 2) อุปกรณ์อยู่ Wi-Fi เดียวกัน 3) ที่อยู่/พอร์ตถูกต้อง 4) Firewall อนุญาต (เครือข่ายส่วนตัว)
"รหัสไม่ถูกต้อง"ดูรหัสล่าสุดในหน้าต่างโปรแกรม (ถ้าเคยกด "สร้างรหัสใหม่" รหัสเดิมใช้ไม่ได้) ใส่ผิดบ่อยเกินไปจะถูกพักการใช้ชั่วคราว รอสักครู่
ภาพขาดเป็นแถบ / สีเพี้ยน (ดูใน Windows Settings ก็เป็น)ปัญหาที่ตัวกล้อง สาย หรือพอร์ต USB: เสียบกล้องพอร์ต USB 3.0 (สีฟ้า) ที่ตัวเครื่องตรงๆ ไม่ผ่าน hub ลองสายสั้น/สายอื่น ถอดอุปกรณ์ USB อื่นออกชั่วคราว ลดความละเอียดเป็น 720p
สถานะ "กล้องค้าง กำลังกู้คืน" ซ้ำๆ จอดำ ข้อความแดงใต้พรีวิวว่า "กล้องถูกโปรแกรมอื่นใช้อยู่"กล้อง USB เปิดได้ทีละโปรแกรมเดียว ปิดหน้า Settings → Cameras ของ Windows (พรีวิวกล้อง), แอป Camera, EMEET Studio, Zoom/Teams และแท็บเบราว์เซอร์ที่เปิดกล้อง แล้วรอสักครู่ โปรแกรมลองใหม่เอง
ข้อความแดง "กล้องไม่รับความละเอียด/fps ที่ตั้งไว้"กล้องบางรุ่นรับ fps เฉพาะช่วง (เช่น EMEET C60E ต่ำสุด 30 fps) โปรแกรมปรับให้ตรงเองอัตโนมัติ ถ้ายังขึ้น ให้เลือกความละเอียดอื่นในรายการ
ยังกู้คืนซ้ำๆ แม้ปิดโปรแกรมอื่นแล้วดูไฟล์ %APPDATA%\RRQC-Camera\camera.log ถอดแล้วเสียบสาย USB ใหม่ ลดความละเอียด/fps
เปิดโปรแกรมแล้วแจ้ง "ไม่พบ ffmpeg.exe"วาง ffmpeg.exe ไว้ข้าง RRQCCamera.exe (บทที่ 8-A)
แจ้ง "เปิดเซิร์ฟเวอร์พอร์ต … ไม่ได้"มีโปรแกรมอื่นใช้พอร์ตนั้นอยู่ เปลี่ยนพอร์ตในหน้าต่างโปรแกรม แล้วกด "บันทึกและใช้ค่านี้" (อย่าลืมแก้ที่อยู่ในหน้าเว็บให้ตรง)
ไม่มีคลิปในช่วงที่เลือกคลิปจะถูกบันทึกเฉพาะตอนมีความเคลื่อนไหว ลองเพิ่ม "ความไว" และตรวจโฟลเดอร์เก็บคลิป คลิปเก่าเกินจำนวนวันที่ตั้งไว้ถูกลบแล้ว

ความปลอดภัย (สำคัญ)

1) repo GitHub ต้องเป็น Private ในโค้ดมีคีย์สาธารณะของ Supabase ฝังอยู่ และฐานข้อมูลตั้งให้ใครก็อ่าน/เขียนได้ ถ้า repo เป็น Public คนอื่นเห็นคีย์แล้วแก้/ลบข้อมูลออเดอร์ สินค้า และประวัติได้ ตั้งค่าที่ Settings → Danger Zone → Change visibility → Make private
2) อย่าเอารหัสดูกล้องหรือที่อยู่ภายในไปโพสต์ที่สาธารณะ
3) อย่าใส่ข้อมูลลูกค้าจริงหรือภาพหน้าจอที่มีข้อมูลจริงลงใน repo

อัปโหลดขึ้น GitHub

  • ใช้ GitHub Desktop (Sign in แล้วกด Push origin) หรือ git push origin main
  • อัปโหลดผ่านหน้าเว็บ GitHub ต้อง ลากทั้งโฟลเดอร์ (css, js, tools, docs) ปุ่ม "choose your files" เลือกโฟลเดอร์ไม่ได้ ไฟล์จะหลุดมาอยู่ระดับบนสุด · ffmpeg.exe และ .exe ที่คอมไพล์เองไม่ถูกเก็บใน git (สร้างใหม่ด้วย build.bat)
