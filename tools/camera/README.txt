RRQC Camera - ติดตั้งบนคอมเครื่องหลักที่เสียบกล้อง

1. วางไฟล์ ffmpeg.exe ไว้ในโฟลเดอร์เดียวกับ RRQCCamera.exe
   (ดาวน์โหลด "ffmpeg-release-essentials" จาก https://www.gyan.dev/ffmpeg/builds/ แล้วแตกเอา ffmpeg.exe จากโฟลเดอร์ bin)
2. ดับเบิลคลิก RRQCCamera.exe (ถ้ายังไม่มี ให้ดับเบิลคลิก build.bat ก่อน)
3. ติ๊ก "เปิดโปรแกรมอัตโนมัติพร้อมวินโดวส์" ถ้าอยากให้เปิดเองทุกครั้งที่เปิดเครื่อง
4. ถ้า Windows ถามเรื่อง Firewall ให้กดอนุญาต (เครือข่ายส่วนตัว)
5. ที่อยู่และรหัสดูกล้องอยู่ในหน้าต่างโปรแกรม ใส่ในหน้า "กล้อง CCTV" ของเว็บ แล้วกด "เชื่อมต่อ"
   (มือถือต้องอยู่ Wi-Fi เดียวกับคอมเครื่องนี้)

ปิดหน้าต่างแล้วโปรแกรมยังทำงานต่อที่ไอคอนในถาดระบบ ออกจริงให้คลิกขวาที่ไอคอน > ออกจากโปรแกรม
