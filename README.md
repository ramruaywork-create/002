# RRQC — ระบบ QC บริษัท ร่ำรวย จำกัด

เว็บแอปตรวจสอบสินค้า (QC) ใช้ Supabase เป็นฐานข้อมูล เปิดได้เลยโดยไม่ต้องติดตั้งอะไรเพิ่ม

## โครงสร้าง

| โฟลเดอร์ / ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บหลัก |
| `css/style.css` | สไตล์ทั้งหมด |
| `js/script.js` | ตรรกะหลักของแอป |
| `js/supabase-api.js` | เชื่อมต่อฐานข้อมูล Supabase |
| `js/scanlog.js` | บันทึกการยิงสแกนเนอร์ในหน้าเว็บ |
| `js/cctv.js` | หน้า "กล้อง CCTV" ฝั่งดู: ดูภาพสด / ดูคลิปย้อนหลัง / สั่งหมุนภาพ จากโปรแกรม RRQC Camera |
| `tools/camera/` | **RRQC Camera** โปรแกรมบนคอมเครื่องหลักที่เปิดกล้อง ตรวจความเคลื่อนไหว บันทึกคลิป และให้เว็บดู (ซอร์ส C#) |
| `tools/cctv/` | สคริปต์เปิดเว็บผ่านเซิร์ฟเวอร์ในเครื่อง และตั้งให้เครื่องไม่หลับ |
| `tools/scanner-logger/` | โปรแกรมบันทึกการยิงสแกนเนอร์ทุกโปรแกรม (ซอร์ส C#) |

## วิธีใช้

- **เปิดเว็บ:** ต้องเปิดผ่านเซิร์ฟเวอร์ในเครื่อง เช่น `python -m http.server 5510` แล้วเข้า `http://localhost:5510/index.html`
  หรือดับเบิลคลิก `tools/cctv/start-cctv.bat` (ต้องมี Python)
- **โปรแกรมสแกนเนอร์:** ดับเบิลคลิก `tools/scanner-logger/build.bat` เพื่อสร้าง `RRQCScanner.exe` (ใช้ตัวคอมไพล์ที่มากับ Windows ไม่ต้องติดตั้งเพิ่ม)

### กล้อง CCTV (RRQC Camera)

โปรแกรมบนคอมที่เสียบกล้องเป็นคนเปิดกล้อง จับความเคลื่อนไหว และเก็บคลิป เว็บเป็นแค่ที่ดู

1. ดาวน์โหลด `ffmpeg.exe` (build "essentials" จาก <https://www.gyan.dev/ffmpeg/builds/>) วางไว้ใน `tools/camera/` ข้าง `RRQCCamera.exe` (ไฟล์นี้ไม่อยู่ใน git)
2. ดับเบิลคลิก `tools/camera/build.bat` เพื่อสร้าง `RRQCCamera.exe` (ใช้ตัวคอมไพล์ที่มากับ Windows)
3. เปิด `RRQCCamera.exe` ครั้งแรกจะเลือกกล้องตัวแรกที่พบให้เอง ปรับความละเอียด/ความไว/โฟลเดอร์เก็บคลิปในหน้าต่างแล้วกด "บันทึกและใช้ค่านี้" ติ๊ก "เปิดโปรแกรมอัตโนมัติพร้อมวินโดวส์" ถ้าต้องการ ปิดหน้าต่างแล้วโปรแกรมยังทำงานที่ถาดระบบ
4. Windows Firewall จะถามครั้งแรก ให้อนุญาต "เครือข่ายส่วนตัว"
5. หน้าต่างโปรแกรมแสดง **ที่อยู่** (เช่น `http://192.168.1.68:8787`) และ **รหัสดูกล้อง** 8 ตัว ใส่ทั้งสองในหน้า "กล้อง CCTV" ของเว็บแล้วกด "เชื่อมต่อ" (ใช้ได้กับมือถือที่อยู่ Wi-Fi เดียวกัน)

ข้อจำกัด:

- ใช้ได้เฉพาะเครื่องที่อยู่ในเครือข่ายเดียวกับคอมที่รันโปรแกรม (ยังไม่รองรับดูจากนอกบ้าน)
- ข้อมูลวิ่งแบบ HTTP ไม่เข้ารหัสในเครือข่ายบ้าน อย่าบอกรหัสกับคนที่ไม่ไว้ใจ (สร้างรหัสใหม่ได้จากหน้าต่างโปรแกรม)
- ต้องเปิดเว็บแบบ `http://` (เช่นผ่าน `start-cctv.bat`) หน้าเว็บที่โฮสต์บน `https://` เรียกโปรแกรมกล้องใน LAN ไม่ได้
- คลิปเก่าที่เคยบันทึกด้วยหน้าเว็บ (`.webm`) ยังแสดงในไทม์ไลน์ได้ ถ้าชี้โฟลเดอร์คลิปของโปรแกรมไปที่เดิม
- ทดสอบอัตโนมัติ: `tools/camera/run-selftest.ps1` (ทดสอบหน่วย) และ `tools/camera/tests/integration.ps1` (ทดสอบเต็มระบบด้วยภาพจำลอง ใช้เวลาประมาณ 2 นาที)
