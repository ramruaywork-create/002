# RRQC — ระบบ QC บริษัท ร่ำรวย จำกัด

เว็บแอปตรวจสอบสินค้า (QC) ใช้ Supabase เป็นฐานข้อมูล เปิดได้เลยโดยไม่ต้องติดตั้งอะไรเพิ่ม

## โครงสร้าง

| โฟลเดอร์ / ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บหลัก |
| `css/style.css` | สไตล์ทั้งหมด |
| `js/script.js` | ตรรกะหลักของแอป |
| `js/supabase-api.js` | เชื่อมต่อฐานข้อมูล Supabase |
| `js/scanlog.js` | บันทึกการยิงสแกนเนอร์ในหน้าเว็บ |
| `js/cctv.js` | กล้อง CCTV บันทึกเมื่อจับความเคลื่อนไหว + ดูย้อนหลัง |
| `tools/cctv/` | สคริปต์เปิดกล้อง CCTV และตั้งให้เครื่องไม่หลับ |
| `tools/scanner-logger/` | โปรแกรมบันทึกการยิงสแกนเนอร์ทุกโปรแกรม (ซอร์ส C#) |

## วิธีใช้

- **เปิดเว็บ:** ต้องเปิดผ่านเซิร์ฟเวอร์ในเครื่อง เช่น `python -m http.server 5510` แล้วเข้า `http://localhost:5510/index.html`
  หรือดับเบิลคลิก `tools/cctv/start-cctv.bat` (ต้องมี Python)
- **โปรแกรมสแกนเนอร์:** ดับเบิลคลิก `tools/scanner-logger/build.bat` เพื่อสร้าง `RRQCScanner.exe` (ใช้ตัวคอมไพล์ที่มากับ Windows ไม่ต้องติดตั้งเพิ่ม)

## หมายเหตุ

- repo นี้มีคีย์สาธารณะของ Supabase ฝังอยู่ในโค้ด และฐานข้อมูลเปิดให้อ่าน/เขียนได้ จึงควรตั้งเป็น **Private**
